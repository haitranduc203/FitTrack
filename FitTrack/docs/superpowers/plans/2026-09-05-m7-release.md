# M7 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a documented, verified FitTrack v1.0.0 release commit and local annotated tag.

**Architecture:** Release work changes metadata and documentation only; application architecture and runtime dependencies stay unchanged. Real emulator screenshots and fresh test/build evidence make the release reproducible.

**Tech Stack:** Android Gradle Plugin, Kotlin, Jetpack Compose, Room, Hilt, DataStore, Gradle, Android CLI/ADB, Markdown/Mermaid.

**Spec:** `docs/superpowers/specs/2026-09-05-m7-release-design.md`

## Global Constraints

- Work on `feature/release`, based on `feature/testing`.
- Do not add runtime dependencies, remote services, or signing secrets.
- Keep the release APK unsigned and document that limitation.
- Do not include Gym visual image/GIF files.
- One coherent task per commit.
- Do not push or merge.
- Cap full connected runs at 360 seconds.
