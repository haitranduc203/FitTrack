# M6 Testing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close M6 with a traceable coverage matrix, one missing Compose validation regression, and fresh full-suite evidence.

**Architecture:** Existing unit, Room, ViewModel, and critical-flow suites remain the primary evidence. Add no new abstraction or dependency; add only the missing UI-boundary test and document exact test-to-requirement mappings.

**Tech Stack:** Kotlin, JUnit 4, kotlinx-coroutines-test, Room in-memory tests, AndroidX Compose UI Test, Gradle.

**Spec:** `docs/superpowers/specs/2026-09-05-m6-testing-design.md`

## Global Constraints

- Keep the single-module MVVM/UDF/Room architecture unchanged.
- Add no production feature or dependency.
- One coherent task per commit.
- Use finite Compose `waitUntil` calls; never add `Thread.sleep`, `GlobalScope`, or unbounded coroutine test advancement.
- Cap each full connected run at 360 seconds.
- Do not push, merge, or create `v1.0.0` during M6.

### Task 2: Add the missing invalid-set Compose regression

**Files:**
- Modify: `app/src/androidTest/java/com/haitranduc/fittrack/FitTrackNavigationTest.kt`

**Interfaces:**
- Consumes: `active_weight_0001` and `active_reps_0001` semantics tags, `R.string.error_invalid_reps`, `R.string.error_invalid_weight`, and `FitTrackDatabase.setLogDao()`.
- Produces: `test_activeWorkout_invalidRepsAndWeight_showErrorsWithoutPersistingSet()`.

- [ ] **Step 1: Write the finite connected test with a deliberately valid reps fixture**

Create the test flow and initially enter reps `10` while asserting `error_invalid_reps`. This deliberate fixture must fail, proving the assertion is capable of detecting absence of the validation state. Cleanup must be safe inside `finally`.

- [ ] **Step 2: Run the test and verify RED**

```powershell

```

Expected: FAIL because the reps error is not displayed for valid reps `10`; command must finish below 180 seconds.

- [ ] **Step 3: Correct the test inputs and assert real behavior**

Use the following observable sequence:

```kotlin

onNodeWithTag("active_reps_0001").performTextReplacement("0")
```
